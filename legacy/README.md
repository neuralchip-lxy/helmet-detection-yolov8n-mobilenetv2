# Historical YOLOv5 work

[`yolov5-master/`](yolov5-master/) preserves the earlier YOLOv5 code and experiment configuration. The paper model described in the repository root uses YOLOv8n and does not depend on this directory.

Generated YOLOv5 training runs and weight files are excluded from this public snapshot. The historical code retains its [upstream license](yolov5-master/LICENSE) and [README](yolov5-master/README.md).
